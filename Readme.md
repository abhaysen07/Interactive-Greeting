📘 Interactive Greeting App – JavaScript Mini Project

A beginner-friendly interactive webpage where the user enters their name, clicks a button, and instantly receives a personalized greeting.
This project introduces the fundamentals of HTML, CSS, and JavaScript DOM manipulation in the simplest and cleanest way possible.

🎯 Project Goal

To understand how user input, event handling, and DOM updates work in JavaScript.
This is a Day-1 JavaScript project that builds your foundation for real frontend development.

🚀 Features

User can type their name in an input box

Button click triggers a greeting

Dynamic message appears on the page

Simple, clean layout

Beginner-friendly JavaScript

No libraries — pure vanilla JS

This covers the core fundamentals needed before moving to bigger projects.

📂 Project Structure
Interactive-greeting/
 ├── index.html   → Main webpage structure + simple styling
 └── script.js    → All JavaScript logic (input + greeting)

▶️ How to Run the Project

Open the project folder in VS Code

Open index.html in any browser (Chrome/Edge/Firefox)

Enter your name in the input box

Click the Click Me button

Enjoy your personalized greeting 🎉

🧠 How It Works (In Simple Words)

User enters their name

JavaScript reads the value using:

input.value


Button click triggers an event

JS checks if the input is empty

If valid, JS updates the DOM with:

output.textContent


That’s your first real interactive DOM project.
Small, simple, but highly valuable.
